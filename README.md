# UNGA Voting Network Analysis  
### Network Science Project — India's Geopolitical Alignment

---

## Research Question  
**Is India a structural "swing state" in UN voting networks, or does it belong to a stable geopolitical bloc?**

## Data Sources

| File | Source | Used for |
|------|---------|----------|
| `votes.csv` | [Kaggle](https://www.kaggle.com/datasets/unitednations/general-assembly) | Core vote data (1946–2015) |
| `resolutions.csv` | Kaggle (same) | Resolution metadata + 6 issue flags |
| `states.csv` | Kaggle (same) | Country ideal-point estimates |
| `AgreementScores.csv` | [Harvard Dataverse](https://dataverse.harvard.edu/dataset.xhtml?persistentId=doi:10.7910/DVN/LEJUQZ) | Pairwise agreement (validation) |

> **Note:** Raw data is **not** committed. Download from the links above and place into `kaggle_files/` and `dataverse_files/`.

## Getting Started

```powershell
# 1. Setup
python -m venv venv
.\venv\Scripts\activate
pip install -r requirements.txt

# 2. Download raw data into kaggle_files/ and dataverse_files/

# 3. Run the pipeline
python scripts/run_p1_data_prep.py   # Phase 1: clean data, temporal slices
python scripts/run_p2_networks.py    # Phase 2: build 11 NetworkX graphs
python scripts/run_p3_p6.py          # Phases 3–6: topology, communities, robustness, dynamics
```

Or run the Jupyter notebooks in `notebooks/` sequentially (01 → 06).

## Methodology

- **Threshold:** θ = 0.70 (θ = 0.55 for issue networks)
- **Vote recoding:** Yes → +1, Abstain → 0, No → −1, Absent/Non-member → dropped
- **Eras:** Cold War (1946–91), Post-CW (91–01), Post-9/11 (01–14), Recent (14–15)
