# UNGA Voting Network Analysis  
### Network Science Project — India's Geopolitical Alignment

## Research Question  
**Is India a structural "swing state" in UN voting networks, or does it belong to a stable geopolitical bloc?**

## Key Methodological Choices

### Threshold θ = 0.70
Agreement scores above 0.70 → edge drawn. Validated by sweeping θ ∈ [0.5, 0.95] 
and selecting the knee where communities become well-separated but the giant 
component stays connected. Issue networks use θ = 0.55 (sparser).

### Vote Recoding
- 1 (yes) → +1  
- 2 (abstain) → 0  
- 3 (no) → −1  
- 8 (absent), 9 (non-member) → dropped

### Temporal Eras
| Era | Years | Rationale |
|-----|-------|-----------|
| Cold War | 1946–1991 | Bipolar world |
| Post-Cold War | 1991–2001 | Unipolar moment |
| Post-9/11 | 2001–2014 | Security-dominated agenda |
| Recent | 2014–2015 | Kaggle data limit |
